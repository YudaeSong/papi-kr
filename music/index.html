YouTube Studio 오디오 보관함 열기

지정한 계정()의 Studio로 열립니다. 열린 화면에서 아래 순서대로 거르세요.

Studio는 Chrome 프로필 gyro.aifactory01(Profile 5)에서 열어야 합니다. 다른 프로필이나 다른 기기에서는 계정 순번이 달라 다른 계정의 Studio가 열릴 수 있습니다.

  1. 처음 한 번: 점선 버튼을 브라우저 북마크바로 끌어다 놓기 → ♪ 필터 적용
  2. 검색창에 붙여넣기 (아래 「검색어 복사」)
  3. Studio 화면에서 북마크 「♪ 필터 적용」 클릭 → 아래 장르·분위기·라이선스 필터가 한 번에 걸립니다. Studio는 필터를 주소에 담지 못해 화면에서 대신 눌러 줍니다. 실패하면 화면 위 안내가 뜨니 아래 순서대로 직접 거르세요.
  4. 필터 → 장르: 영화(Cinematic)
  5. 필터 → 분위기: 극적(Dramatic), 영감(Inspirational)
  6. 필터 → 라이선스 유형: 저작자 표시 필요 없음
  7. 목록 머리의 「추가된 날짜」를 누르면 등록일순으로 정렬됩니다. 각 곡의 ▶로 미리 듣기, ⬇로 내려받기.
오디오 보관함 열기 ↗

YouTube 오디오 보관함은 공개 API가 없고 로그인한 Studio 안에서만 열려 이 화면에 목록을 가져올 수 없습니다. Studio도 재생·다운로드 수는 보여 주지 않습니다.
